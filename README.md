<b><H1>Apex Engine</H1></b>

A game engine using OpenGL for 3D games. This is a solo project and I intend to keep this public for now under the MIT license.

Requirements: 
- CMake Version 3.70+
- Windows/Linux supported
- Git

Install:
- Clone the repo to any location on your computer. ```C:/Users/Username/Desktop/apex-engine/ ```
- Create a build folder in the main directory ```C:/Users/Username/Desktop/apex-engine/build/ ```
- CD into the build folder inside a terminal ```cd C:/Users/Username/Desktop/apex-engine/build/ ```
- Run ```cmake .. ```

Windows:
- Open the .sln file and build

Linux:
- Run ```make``` while in the build folder

This project should work with Visual Studio Code as well. Just open the folder that you cloned and if you have the C++ and CMake Tools extensions, 
it should be recognized and will automatically make a build directory for you on Linux or Windows. 

Press ```Shift+F5``` in VSCode to build with CMake.
